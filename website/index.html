给定一个整数数组 nums 和一个目标值 target，请返回和为 target 的两个元素的下标。

输入：nums = [2,7,11,15], target = 9
输出：[0,1]
建议回答
def two_sum(nums, target): seen = {} for i, n in enumerate(nums): if target - n in seen: return [seen[target - n], i] seen[n] = i return []

哈希表一次遍历，时间 O(n)，空间 O(n)。

常见问题

常见问题

需要联网吗？+

本地识别可离线；生成回答需要联网。

支持哪些面试软件？+

Windows 上能出声的软件都支持。线上选电脑声音，线下用麦克风。

笔试模式怎么用？+

按 Alt+Shift+A 框选题目，答案在悬浮窗或手机显示。

防录屏隐身真的看不到吗？+

窗口在屏幕共享和录屏中不可见，建议面试前自测。

换电脑后要重新下载模型吗？+

需要重新下载模型，账号不受影响。

支持 macOS 或手机吗？+

仅支持 Windows 10 / 11（x64），手机只作为副屏。
